Reachy Mini Wireless App

HeyRobo

Wake-word gated OpenAI Realtime conversations for Reachy Mini, with a local Codex relay for hands-free development tasks on your WiFi network.

Made by Adrian with Codex - curiosityai.nl

Runtime

Always Local Until "Hey Robo"

01

Wake Gate

Vosk listens locally for a configurable phrase before any Realtime session starts.

02

Realtime Voice

OpenAI Realtime runs only during the active conversation and can return to standby on command.

03

Codex Relay

The assistant can dispatch authenticated tasks to a local Codex relay and branch automatically.

Install

Reachy Mini App Store Ready

uv sync
reachy-mini-daemon --sim
python -m hey_robo

Configure the OpenAI API key, wake phrase, voice, Vosk model path, and Codex relay from the installed app settings page.

The dashboard includes a live log window for calls, usage, wake events, relay activity, and errors.
